Plane Sound Privacy Policy

Last updated: May 24, 2026

Overview

Plane Sound is an aircraft sound awareness tool. It uses a location selected by the user to estimate nearby aircraft activity and possible microphone contamination risk.

Location Data

Plane Sound uses location only when the user chooses to use current location, manual coordinates, or location search. Location is used to request nearby aircraft data and display aircraft activity near that point.

Local Storage

Plane Sound may store app settings, selected location, hidden microphones, and custom microphone records locally on the device using browser storage. This data is used only to keep the app working between sessions.

Network Requests

Plane Sound sends location coordinates to its aircraft and geocoding services when needed to provide aircraft and location results. Plane Sound does not use accounts, advertising tracking, or behavioural advertising.

Microphone Data

Custom microphone data entered by the user is stored locally on the device. It is not used to identify the user.

Data Sale

Plane Sound does not sell user data.
